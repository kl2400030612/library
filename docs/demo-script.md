# 5-minute demo script

1. Open Archvialia and show the login screen.
2. Login as the demo user.
3. Open Library and search for a book.
4. Show availability and borrow the resource.
5. Open My Borrowings and show the active loan/due date.
6. Return the book and show the returned state.
7. Open My Fines. Explain that Fine Service calculates overdue days × daily rate.
8. Sign in as ADMIN and show the admin catalogue controls.
9. Explain the architecture: Gateway → services, Eureka discovery, LoadBalancer, JWT security.
10. Open Eureka dashboard to show registered services.
